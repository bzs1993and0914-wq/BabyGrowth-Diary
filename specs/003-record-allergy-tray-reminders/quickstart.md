# Quickstart: 手动验收 003-record-allergy-tray-reminders

前置：本地以开发或打包模式启动桌面应用，后端健康检查通过。

## 1. 日期不得超过今天

1. 打开创建记录或编辑记录日期选择器。
2. 确认未来日期不可选；若 API 直接提交未来 `date`，应返回 4xx 与明确错误信息。

## 2. 过敏字段与展示

1. 在某条记录中填写过敏文本并保存；重新打开应回显。
2. 时间轴/记录列表中该条出现醒目样式（颜色/文案）。
3. 从首页入口进入聚合页，确认所有非空过敏记录均出现，日期倒序合理。

## 3. 每日 10:00 提醒

1. **Electron 桌面**：使用 `npm run dev`（或打包客户端）启动，保证主进程在跑；若仅用 `npm run dev:vite` 打开浏览器，则只有页面内 Element 通知（无系统通知）。
2. 将系统时间调至当日 9:58 左右（或使用实现提供的调试钩子若已添加），启动应用。
3. 等待跨越 10:00：应出现至少一次含义为「该给宝宝创建新的记录啦」的提示——**应用内右上角通知**（Electron 打开窗口时必有）及/或**系统通知**（需系统允许 BabyGrow 通知）。
4. 若系统通知被关闭：仍应看到应用内通知；仅当无可用窗口且系统通知不可用时，才会弹出对话框兜底。
5. 同日不会再弹；改到次日 10:00 可再验证一次。

## 4. 托盘与退出

1. 点击窗口关闭：主窗口消失，托盘区出现应用图标。
2. 单击图标：主窗口恢复聚焦。
3. 托盘菜单「退出」：进程结束，后端子进程不再残留（按当前 `main.ts` 行为验证）。
